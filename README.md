## Featured projects
 
### [VIGIL: Bearing Fault Monitoring Prototype](https://github.com/rithikraghav-eng/VIGIL-Bearing-Fault-Monitoring-Prototype)
Low-cost motor-health monitoring using vibration analysis.
- Computes BPFO / BPFI / BSF for a 6205 bearing and flags faults using a Hann-windowed FFT against a captured healthy baseline
- Simulation mode (synthetic healthy and fault signals) and live mode (3-axis accelerometer over USB serial)
- README documents known limitations and a validation roadmap
- **Stack:** Python, NumPy, SciPy, Matplotlib, Arduino-compatible board
### [STM32 Microcontroller Simulator](https://github.com/rithikraghav-eng/stm32-microcontroller-simulator)
An educational ARM Thumb CPU emulator in Python (a subset, not a full Cortex-M4 model).
- 16-bit Thumb instruction subset with unit tests
- STM32F411RE Flash/SRAM model with limited GPIOA/RCC memory-mapped peripherals
- Strict ELF32 ARM parser and loader for running compiled test firmware
- **Stack:** Python, ARM assembly
